# ReviewIQ – Intelligent Review Analysis System

ReviewIQ is a seller-side analytics platform that transforms e-commerce customer reviews into meaningful product insights.

It analyzes review text, ratings, and sentiment to help sellers understand what customers like, what problems they repeatedly mention, and which product areas may need improvement.

---

## 🚀 Features

- 📂 Upload product reviews through a CSV file
- 🧹 Review text preprocessing and cleaning
- 🤖 Machine-learning based sentiment analysis
- 📊 Interactive sentiment visualization
- ⭐ Rating distribution analysis
- 💪 Identification of product strengths
- ⚠️ Identification of product weaknesses
- 💡 Actionable seller recommendations
- 🌙 Dark SaaS-style analytics dashboard
- 📈 Interactive Plotly visualizations
